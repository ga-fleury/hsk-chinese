# HSK 1 means HSK 3.0 Band 1 (500 words)

Two standards compete for the name "HSK 1": the classic HSK 2.0 list (150 words, used by the current official exam) and the HSK 3.0 standard (2021, 500 words). We deliberately chose HSK 3.0 Band 1 for broader coverage, accepting a 3× larger beginner scope and a mismatch with the exam as administered today. The dataset and all saved scheduling state are keyed to this list, so switching standards later would orphan progress.
